##  Опис роботи
У цій лабораторній роботі досліджуються:
1. Перетворення між гамма-кодованим простором sRGB та лінійним простором світла.
2. Правильне зменшення роздільної здатності (downscaling) шахівниці в лінійному просторі без спотворення яскравості.
3. Колірна модель **YCbCr** та виділення каналу яскравості $Y$.
4. Колірна модель **HSV** та експерименти з модифікацією тону ($H$) і насиченості ($S$).

---

##  Структура репозиторію

* **`lab2.py`** — основний Python-скрипт з алгоритмами та обчисленнями.
* **`photo.jpg`** — вхідне зображення для експериментів.
* **Результати обробки:**
  * `board_naive.bmp` — наївно зменшена шахівниця.
  * `board_correct.bmp` — правильно зменшена шахівниця (у лінійному просторі).
  * `photo_y_channel.png` — фотографія в градаціях сірого (канал $Y$).
  * `photo_naive_gray.png` — наївне чорно-біле зображення (арифметичне середнє RGB).
  * `hsv_saturation_low.png` — результат зменшення насиченості ($S \times 0.3$).
  * `hsv_saturation_high.png` — результат збільшення насиченості ($S \times 2.0$).
  * `hsv_hue_shifted.png` — результат зсуву тону ($H + 60^\circ$).
